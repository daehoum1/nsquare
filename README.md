 YOLO26n 모델의 변형을 두 가지 만들고 싶어. P3/P4/P5는 stride 8/16/32 특징을 뜻해. 두 모델 모두 backbone 전체는
  유지하고, neck과 검출 경로만 수정해 줘. 1. P3/P4 모델: neck의 마지막 P4->P5 경로와 P5 검출 분기를 제거하고, P3와
  P4에서만 검출해 줘. Backbone의 P5는 남겨 둬. 2. P4/P5 모델: neck의 P4 -> P5 경로와 P3 -> P4 복귀 경로, P3 검출
  분기를 제거해 줘. Backbone P5 정보를 받아 만든 중간 P4 특징에서 바로 검출하고, 이를 downsample한 뒤 backbone P5와
  결합해 P5 검출용 특징을 만들어 줘. 실제 레이어 연결을 확인해서 수정하고, 출력을 무시하는 대신 해당 계산 경로를
  실제로 삭제해 줘. 수정 후에 forward가 정상 동작하는지 확인해 줘. 우리가 이렇게 하는 목적은 모델 경량화야.
